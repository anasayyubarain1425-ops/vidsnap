# VidSnap - Universal Video Downloader

- One-line positioning: Paste any video URL and download it in your preferred quality and format
- Target users: General users who want to save videos from YouTube, Twitter/X, Instagram, TikTok, Facebook, etc.
- Core features:
  1. URL input field — paste any video link from any supported platform
  2. Video info preview — shows thumbnail, title, duration, and available formats/qualities
  3. One-click download — select quality (1080p, 720p, 480p, 360p, audio-only) and download
- Important features (P1):
  1. Supported platforms display (YouTube, TikTok, Twitter/X, Instagram, Facebook, Vimeo, etc.)
  2. Copy/paste button for quick URL input
  3. Download history (session-based, in-browser)
- Device strategy: adaptive
- Design style: Modern Dark Tech — near-black background, cyan→green gradient accents, premium SaaS feel
- Technical constraints: Uses yt-dlp via Next.js API route (server action) for video metadata & download URLs
- Completed: design system, brief
- Current iteration: full UI + API backend
